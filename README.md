## Desafio Node.js com Javascript Jitter

  <p>O projeto foi concebido a partir do desafio da empresa Jitter para criar uma API capaz de gerenciar (crud) de dados de pedidos chamado Order e Items vinculados ao pedido.<br/>
     O Conteúdo do desafio foi utilizar o node.js com Javascript para criar a API mencionada acima, tendo como objetivo construir uma aplicação back-end node.js e Javascript para disponibilizar serviços API com conexão de banco de dados SQL ou PostgreSQL ou MongoDB, e optei pelo MongoDB. Onde utilizei o Insomnia para fazer requisições, simulando o usuário front-end final passando parâmetros via endpoint e objeto JSON, conseguindo consultar a base de dados no MongoDB pela API para trazer o objeto resultante de inserção, atualização, consulta geral e específica e finalmente a exclusão. Além do aprendizado de construir um serviço API do zero passo a passo incluíndo banco de dados, este projeto permitiu conhecer e utilizar as ferramentas express e prisma como pontes entre requisito e estrutura, além do próprio Node.js para este fim.
   </p>
   <br/>
   <p>
      Valendo destacar, que não havia feito um projeto node.js até então, após pesquisas e busca de conteúdo, foi possível chegar ao resultado final, agradecendo as fontes de pesquisa.
     Destacando que no vídeo no fim da página, eu explico o funcionamento da aplicação e comandos utilizados para criar o projeto, instalar dependências e enviar o schema local para o Mongo DB.
   </p>
   
  ## Conceitos
  
 - Estrutura Node.js e Javascript
 - Elementos, objetos, métodos, funções normais, funções assíncronas, estrutura condicional, tratamento de exeções com try catch, eventos, mapeamento de requisições para API, variáveis (let,var e const), dependências, instâncias.
 - Manipulação de arquivos de configuração, modelagem do banco de dados, definição de constante de ambiente.
 - Criação de cluster, banco de dados e manipulação de documentos via plataforma Mongo DB.
